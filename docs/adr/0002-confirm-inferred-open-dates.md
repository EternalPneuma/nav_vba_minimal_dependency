# 推算开放日必须经人工确认

开放日台账是已确认开放日的权威来源，理论间隔推算只能产生待确认记录，不能直接写入台账。周开产品取基准日期之后下一周的周三；183日特殊产品中，6个月101取每月最后一个周三，6个月102取每月第二个周三；其他正数从最近一个已知开放日起按自然日间隔滚动。遇节假日时由业务人员在确认环节顺延日期；确认后，Data02 才写入台账并继续计算。该流程增加了一次人工检查，但避免理论间隔录错或推算缺少锚点时把猜测永久固化为金融报表依据。

## Consequences

一键流程发现待确认记录时正常中止并保留已导入净值；再次运行时消费已确认记录。Tool03 与 Data02 复用同一个开放日提议模块，不再分别维护算法。
