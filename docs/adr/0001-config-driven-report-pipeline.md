# 使用工作簿配置驱动统一报表流水线

报表必须在仅有 Excel 2007/VBA、几乎无法联网的内网环境运行，同时主要维护者只能修改工作表。系统采用主工作簿中的受控配置表驱动分类、展示分组、输出字段方案和图表位置，并由统一指标计算与渲染模块解释配置；不再为每个分类复制专用 VBA，也不允许业务人员在配置中编写计算公式。这样牺牲了一部分任意布局能力，换取新增产品归属时无需修改代码、计算口径集中以及可在运行前严格预检。

## Consequences

产品归属名称可以自由增加，但必须引用受支持的视觉主题、标准指标和组合图类型。新增计算指标或全新版式仍需修改 VBA。主工作簿是运行时配置的权威来源，Python、PowerShell和 VBProject 权限只用于外网开发部署。
