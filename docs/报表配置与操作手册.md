# 报表配置与操作手册

> 本手册对应配置驱动的产品净值周报流程，运行环境为 Excel 2007/VBA。首次迁移完成前，请勿按本文新增配置。

## 日常流程

1. 将181净值文件及所需外部数据放到主工作簿同级目录。
2. 打开并保存主工作簿。
3. 运行 `AAA启动控制台`，选择“一键生成展示文件”。
4. 如果流程生成“开放日待确认”，核对推算日期并填写确认状态，然后再次运行一键流程。
5. 检查最终汇总中不存在配置错误、关键指标缺失或必需图表缺失。
6. 使用与基准日期一致的 `yyyyMMdd-产品收益展示.xlsx`。

## 主数据职责

| 工作表 | 维护内容 |
|---|---|
| 产品分类 | 产品是否导出、唯一产品归属和产品系列 |
| 产品信息 | 信托计划代码、成立日和产品简称 |
| 报表配置 | 分类、展示分组、输出字段方案、展示报表图表用途和推荐材料产品范围 |
| 开放日 | 已确认开放日 |
| 开放日待确认 | 根据理论间隔推算但尚未确认的开放日 |
| 绘图净值数据 | 生成长期图表所需的历史数据 |

同一个业务字段只在其权威工作表维护。预检发现冲突时，流程停止而不是自动选择。

## 产品增减与归属

- 新增产品：在“产品分类”和“产品信息”中填写完整主数据，并设置“是否导出”为“是”。
- 暂停导出：将“是否导出”改为“否”；不要删除产品行、净值或开放日历史。
- 改变归属：修改“产品分类”的分类值，并确认“报表配置”中存在对应且启用的分类配置。
- 每个产品永久只有一个产品归属。

## 报表配置

“报表配置”包含五个独立 Excel 表格。可以新增、删除和排序数据行，但不要修改表名、删除表头或合并单元格。

### 分类配置

维护分类启停、工作表名称、主标题、页内标题、视觉主题和工作表顺序。分类名称可以自由增加，但必须先通过预检。工作表名称必须唯一、最多31字符，且不能包含 `\ / ? * [ ] :`。

视觉主题当前只允许：

- 红
- 蓝

### 展示分组配置

通过“分类 + 产品系列”把产品映射到展示分组。每个展示分组配置显示标题、顺序和一个输出字段方案。同一展示分组不能引用多个输出字段方案。

### 输出字段方案

每个方案必须包含“产品名称”，并最多再选择四个标准指标。业务人员可以调整指标顺序和显示标题，但不能填写公式或创建未登记指标。

初始标准指标包括：

- 产品名称
- 下一开放日
- 开放频率
- 基准收益率
- 当前周期运作天数
- 上一周期年化
- 当前周期年化
- 7日年化
- 28日年化
- 成立以来年化

中间分类表现报表将缺失指标保存为空单元格；最终展示报表将允许缺失的指标显示为 `\`。关键数据缺失会阻止正式输出。

### 图表位置配置

使用信托计划代码指定产品，以位置序号决定图表在分类周报中的顺序。不要填写单元格地址。当前只支持“净值+30日年化收益率组合图”。正式流程要求必需图表生成成功且图表日期与报表基准日期一致。

### 推荐材料产品配置

`tblWeeklyRecommendationProducts` 是推荐材料产品范围的权威来源，维护信托计划代码、是否启用、展示顺序和图表主题。图表主题只允许“红”或“蓝”，展示顺序在已启用产品中必须唯一。

首次迁移会从“产品要素”导入现有产品，默认全部启用并使用蓝色主题；以后在“产品要素”新增产品时，还需由业务人员手工加入本配置表。

“一键生成推荐材料”只检查与基准日期完全一致的图片目录。所需图片全部存在时跳过图表步骤；任意图片缺失时完整运行图表流水线。重跑后仍缺少指定主题图片，或产品简称、净值缺失时，停止正式输出，不使用其他日期或其他主题图片兜底。

### 一页通版本配置

`tblOnePageVersions` 逐行定义一页通版本，包括启停状态、输出顺序、模板相对路径、输出文件前缀、基准产品和两个顶层产品。模板路径必须位于主工作簿目录下，不能使用绝对路径或 `..`。

初始启用版本：

| 版本 | 基准产品 | 顶层产品1 | 顶层产品2 |
|---|---|---|---|
| 交鑫致远6月 | OA4400 | P83600 | P83800 |
| 交鑫致远12月 | OA4400 | Q87500 | Q87900 |

每个模板必须且只能包含一个 `chart_000`、`chart_001`、`chart_002` 和 `table_000`。三个图表依次对应基准产品、顶层产品1和顶层产品2；表格用于更新两个顶层产品在基准日的资产净值合计。

一页通使用独立预检，不影响普通周报。流程先从181数据同步配置所需净值，再要求所有产品具备与基准产品最新净值日一致的有效净值。Excel图表保存并重开验证后才替换正式中间文件；全部启用版本均生成并验证成功后，才同时替换正式PPT。不再生成PDF，历史PDF不会删除。

## 开放日待确认

理论间隔均按自然日解释：

- 1：不推算；
- 7：取下一周周三，即使基准日期当天为周三也取下周；
- 183：6个月101取每月最后一个周三，6个月102取每月第二个周三；遇节假日时在待确认环节顺延；
- 其他正数：从最近一个已知开放日反复增加理论间隔，直到得到基准日期之后的日期；
- 没有已知开放日锚点：不自动猜测，必须人工处理。

推算结果只有确认后才写入“开放日”台账。拒绝或未处理的记录不会成为计算依据。

## 缺失与错误处理

以下情况会在预检阶段阻止正式流程：

- 产品分类没有对应分类配置；
- 分类、展示分组、字段方案或视觉主题无效；
- 同一展示分组配置不同字段方案；
- 信托计划代码未登记；
- 工作表名称非法或重复；
- 图表位置重复；
- 关键净值、日期或必需图表缺失；
- 图表日期与基准日期不一致。

输出文件先写入临时文件并校验，成功后才替换正式文件；失败时保留原文件。

## 恒丰初始配置

- 产品归属：恒丰
- 视觉主题：红
- 输出字段方案：与稳享长期限相同
- 风险提示：沿用现有交通银行原文
- 顶部图表：`PE3300`、`PH3400`

## 外网开发回归

可使用以下命令比较两个中间报表或展示报表的工作表、合并区域和单元格值：

```powershell
python scripts/py/compare_report_workbooks.py 旧报表.xlsx 新报表.xlsx
```

开放日修复引起的差异需要单独复核；其余差异应视为潜在回归。该脚本只用于外网开发，不属于内网运行依赖。

## 维护原则

- 不在配置单元格中写VBA或Excel计算公式。
- 不用产品名称或产品简称代替信托计划代码。
- 不通过删除历史数据停用产品。
- 不使用与基准日期不一致的旧图表。
- 修改配置后先运行预检，再运行正式流程。
